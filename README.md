## Featured project

### [Clear Technical English](https://github.com/yusufys/clear-technical-english)

A Codex skill for clear, readable technical communication in **CEFR B1–B2 English**, while keeping technical terminology precise.

Use it during brainstorming, implementation, progress updates, and reports of what was built or changed.

#### Install

Clone the skill repository and copy its `SKILL.md` into your user skills directory:

```bash
git clone https://github.com/yusufys/clear-technical-english.git
cd clear-technical-english
mkdir -p ~/.codex/skills/clear-technical-english
cp SKILL.md ~/.codex/skills/clear-technical-english/SKILL.md
```

For installation in a single repository, see the [installation guide](https://github.com/yusufys/clear-technical-english#install-only-for-one-repository).

#### Try it

```text
Use the clear-technical-english skill.
```

Codex can also select the skill automatically based on its description.
